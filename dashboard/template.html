사이트 설명

현대엘리베이터 모바일 앱 선행연구 — Hermes 에이전트 라이브 대시보드

한 줄 요약

MuJoCo 시뮬 환경에서 SO-ARM101 로봇팔의 모방학습(ACT/DP) 을 단계적으로 구축해 PCB 픽앤플레이스 시연(2026-10) 까지 가는 6개월 프로젝트의 진척 대시보드.

매일 자동으로 시뮬 작업이 진행되고 (research/simulation/), 테스트 결과가 누적되며 (research-log/), 월말 보고서용 증거가 정리됩니다 (report-evidence/). 이 사이트는 그 누적된 진척을 한 페이지에서 보고, 검색하고, 외부 의존 항목과 다음 단계를 점검하는 도구입니다.

왜 만들었나

  • 가시성: Phase 0~5, 6개월(180+ 시뮬 작업) 의 진척을 한눈에 — 폴더 트리로는 안 보임
  • 의존 추적: 실기팀/외부 머신/사용자 수동 처리 항목을 마감일·담당자별로 → "왜 진행이 멈췄나" 즉시 확인
  • 증거 큐레이션: 일일 진척에서 보고용 증거 후보를 자동 추출 → 월말 보고서 작성 시간 절약

  • 매일 23:30 — 시뮬 테스트 + 메트릭 수집 + 대시보드 rebuild
  • 매일 01:00 — 야간 retry watchdog (실패 잡 자동 재시도)
  • 매일 07:00 — 아침 보고 메일 발송

Phase 로드맵 (6개월)

좌측 Phase 로드맵 메뉴에서 주차/일별 체크리스트 확인:

  • Phase 0 (5월) — 시뮬 환경 셋업 (MuJoCo 설치 → SO-ARM101 import → 카메라/매핑/Pick-Place)
  • Phase 1 (6월) — 사전학습 (데이터 합성 200ep → ACT 학습 → 추가 데이터/재학습)
  • Phase 2 (7월) — Sim2Real 검증 (실기 50ep 수집 + 시뮬↔실기 비교)
  • Phase 3 (8월) — PCB 조정 (실제 PCB 픽앤플레이스 학습)
  • Phase 4 (9월) — RS232 HHT 결선 (DP 비교 + 하드웨어 통신)
  • Phase 5 (10월) — 통합 시연 (사내 발표, PCB 70% / RS232 부분성공 40%)

일일 의사결정 흐름

  1. 아침: 아침 보고 메일 + 본 대시보드 현재 단계 확인
  2. 외부 의존 차단 메뉴 — 막힌 항목 / 마감 임박 / 담당자 분류
  3. 오늘 작업이 어제 산출물과 어떻게 이어지는지 일일 진척 카드로 확인
  4. 월말: 월간 보고용 증거 메뉴에서 보고서 [2.X] 섹션 매핑

사용가이드

5분 안에 익히는 사이트 사용법

1. 12개 메뉴 둘러보기

  • 현재 단계 — 오늘의 작업 / 최근 시뮬 작업 / 60일 활동 히트맵
  • Phase 로드맵 — Phase 0~5 진행률 + 주차/일별 체크리스트
  • 시뮬 작업 — research/simulation/*.md 카드 (검색·필터·정렬)
  • 일일 진척 — agent/research-log/ 매일의 메트릭·이슈·자가치유
  • 월간 보고용 증거 — agent/report-evidence/YYYY-MM/ 보고서 매핑
  • 외부 의존 차단 ⭐ — 사용자 / 실기팀 / 외부 머신 수동 처리 대기 항목
  • 샘플 코드 상태 ⭐ — samples/ 카테고리별 완성도 / 마지막 검증일
  • 결정 ⭐ — research/decisions/ 아키텍처 결정 기록
  • 사이트 설명 / 사용가이드 / 북마크 / 분석

2. 검색

우상단 검색창에 키워드 입력 또는 / 키. 제목, 본문 요약, Phase, 카테고리, 스크립트명에서 매칭.

3. 필터 & 정렬

상단 chip 으로 Phase 0~5 / 카테고리 / 진행상태 필터. 우측 드롭다운으로 최신순 / 카테고리순 / 북마크순 정렬.

4. 북마크 & 메모

카드 우상단 ☆ 클릭 → 좌측 북마크 메뉴에 모임. 시트에서 메모 버튼으로 코멘트 자동 저장. 모두 이 브라우저의 localStorage 에 저장됨.

5. 다크/라이트

좌측 하단 토글. 시스템 prefers-color-scheme 자동 감지.

6. 키보드 단축키

1~8라우트 전환 (현재단계/로드맵/시뮬작업/일일/증거/차단/샘플/결정)
/검색창 포커스
Esc시트 닫기 또는 입력창 포커스 해제

7. 라이브 갱신

브라우저 열어두면 자동 푸시. 매일 23:30 cron 잡 끝에 data.json 이 갱신되고, hermes-mark 사이트가 chokidar 로 감지 → WebSocket 으로 새로고침 없이 도착.

8. 정적 산출물

인터넷 없는 다른 맥으로 옮길 때: dashboard.html 한 파일만 USB 로 옮기면 즉시 동작. data.json + dashboard.html 은 .gitignore 되어 있어 build.py 로 재생성.
