## 검색 활용

상단 오른쪽 검색창(또는 `/` 키)에 키워드를 입력하면 전체 데이터에서 검색합니다:
- 검색 대상: 시뮬 작업 제목, 본문 요약, Phase 레이블, 카테고리, 스크립트명
- 부분 일치 지원: "pick" → "Pick-Place", "sim_pick_place.py" 등 모두 검색
- `Esc` 키로 검색 취소

**실용 예시**
- "ACT" → ACT 학습 관련 작업 모두 표시
- "sim_pick_place" → 픽앤플레이스 스크립트 언급 작업 표시
- "6월" 또는 "2026-06" → 날짜 기준 필터링

## 필터 & 정렬 (시뮬 작업 화면)

**Phase 필터**: 상단 chip 버튼(Phase 0~4)을 클릭해 해당 Phase 항목만 표시. "전체"로 돌아오려면 "전체" chip을 클릭.

**카테고리 필터**: 드롭다운에서 MuJoCo/MJCF, Camera, ACT 등을 선택. 카테고리는 파일 내용을 분석해 자동 부여되므로 수동 태깅이 필요 없습니다.

**정렬**: "북마크된 순"으로 바꾸면 내가 표시한 중요 항목이 위로 올라옵니다. 특정 작업을 나중에 다시 찾을 때 유용합니다.

**카드 vs 리스트 뷰**: 우상단 토글로 카드(큰 카드)/리스트(컴팩트 행) 전환. 항목이 많을 때는 리스트 뷰가 스크롤하기 편합니다.

## 북마크 & 메모

**북마크 추가**: 카드 오른쪽 위 ☆ → ★로 변하며 북마크 등록. 왼쪽 사이드바 "북마크" 메뉴에서 모아볼 수 있습니다.

**메모 작성**: 항목 클릭 → 상세 시트 열기 → "메모" 버튼 클릭 → 텍스트 입력(자동 저장). 보고 시 코멘트나 다음 액션을 기록해두세요.

**저장 위치**: 북마크와 메모는 이 브라우저의 localStorage에만 저장됩니다. 다른 기기에서는 보이지 않습니다.

## 영상 재생 팁

**시뮬 동작 영상**: "시각자료" 화면에서 각 영상 카드를 클릭해 바로 재생할 수 있습니다. 영상 아래 설명에 "학습 전 IK 기반"이라고 표시된 것은 AI가 학습한 결과 영상이 아닙니다 — 데이터 수집용 시뮬입니다.

**학습 데이터셋 영상**: 맨 아래 데이터셋 영상은 파일이 클 수 있습니다(27MB 이상). 클릭해야 로드가 시작됩니다.

**프레임 시퀀스**: 천장 카메라·그리퍼 카메라의 정지 프레임을 슬라이드 형태로 볼 수 있습니다. 학습 입력 시점을 확인할 때 유용합니다.

## 라이브 갱신

브라우저를 열어두면 매일 23시 30분 이후 자동으로 최신 데이터로 갱신됩니다. 새로고침 없이 WebSocket으로 자동 반영됩니다. 인터넷 연결이 끊겨 있으면 갱신이 안 되며, 연결 복구 시 자동으로 재연결됩니다.

## 다크/라이트 모드

왼쪽 사이드바 하단의 "라이트 / 다크" 토글로 전환합니다. 처음 접속 시 운영체제의 다크모드 설정을 자동 감지합니다.

## 오프라인 배포

인터넷이 없는 환경에서 보여줄 때: `dashboard.html` 단일 파일만 USB로 옮기면 브라우저에서 바로 동작합니다. 서버 없이도 모든 데이터가 HTML 안에 포함되어 있습니다.

## 보고용 자료 인쇄

"보고용 자료" 화면에서 월별 카드를 클릭해 본문을 펼친 다음, ⌘P(Mac) 또는 Ctrl+P(Windows)로 인쇄하면 인쇄 친화적 레이아웃으로 출력됩니다.
