## 이 대시보드가 뭔가요?

SO-ARM101 로봇팔 모방학습 프로젝트(CoP Physical AI)의 진척을 한 화면에서 확인하는 도구입니다. 매일 자동으로 시뮬레이션이 진행되고 그 결과가 이 사이트에 반영됩니다.

## 5분 안에 파악하는 순서

**1단계 — Overview(현재 단계) 화면 확인**
왼쪽 사이드바 맨 위 "Overview"를 클릭하거나, 처음 접속하면 자동으로 이 화면이 나타납니다.
- 오른쪽 위 초록 박스: 목표일(9월 30일)까지 남은 날수
- 진행률 바: 초록 막대 = 현재 달성률 / 세로선 = 오늘 날짜 위치
- KPI 카드 3개: 시뮬 작업 수 / 연구 로그 수 / 해결 대기 중인 외부 의존 수

**2단계 — Phase 로드맵 확인**
왼쪽 사이드바 "Phase 로드맵"을 클릭합니다. 현재 진행 중인 Phase 카드가 파란 배지로 표시됩니다. 그 카드의 체크리스트를 보면 "지금 어떤 작업을 하는 중인지" 알 수 있습니다.

**3단계 — 오늘 작업 확인 (활동 타임라인)**
왼쪽 사이드바 "활동 타임라인"을 클릭합니다. 가장 최근 날짜 카드가 맨 위에 있습니다. 어제 밤 시뮬 작업이 정상 완료됐는지 확인할 수 있습니다.

**4단계 — 막힌 것이 있나? (외부 의존 차단)**
왼쪽 사이드바 "외부 의존" 항목이 보이거나, Overview의 "외부 의존" KPI가 0이 아니면 사람이 직접 처리해야 할 일이 있다는 뜻입니다. 클릭해서 무엇이 막혀 있는지 확인하세요.

## 일상적인 사용 흐름

```
아침 7시 보고 메일 수신
  ↓
Overview 화면 → 전일 진척 확인
  ↓
외부 의존 화면 → 막힌 항목 해결
  ↓
활동 타임라인 → 구체적인 작업 내용 확인
  ↓
(월말) 보고용 자료 → 월별 보고서 열어서 확인/인쇄
```

## 키보드 단축키

| 키 | 이동 |
|---|---|
| `1` | Overview |
| `2` | Phase 로드맵 |
| `3` | 시뮬 작업 |
| `4` | 활동 타임라인 |
| `5` | 보고용 자료 |
| `6` | 외부 의존 |
| `7` | 샘플 코드 상태 |
| `8` | 결정 |
| `/` | 검색창 포커스 |
| `Esc` | 상세 시트 닫기 |
