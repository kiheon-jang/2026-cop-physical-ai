## 기능명세
<!-- slide title="외부 의존 차단 — 개요" -->

외부 의존 차단 화면(`view-blockers`)은 프로젝트 진행을 막고 있는 외부 의존 항목 — 사용자, 실기팀, 또는 외부 머신의 수동 처리가 필요한 것들 — 을 한 화면에서 관리하는 화면이다.

**헤더**
제목: "외부 의존 차단". 부제: "agent/external-dependencies.md · 사용자 / 실기팀 / 외부 머신의 수동 처리가 필요한 항목".

<!-- slide title="항목 파싱과 필드" screenshot="" -->
**항목 목록 (blockers-rows)**
`build_blockers()`가 `agent/external-dependencies.md`를 파싱해 반환한 배열에서 행 목록을 생성.

파싱 패턴: `- [ ] [담당자] **항목명** *(마감일: YYYY-MM-DD)*` 형식 또는 단순 `- [ ] 항목명`.

각 항목 필드:
- `checked`: 완료 여부 (`[v]` = 완료, `[ ]` = 미완료)
- `owner`: 담당자(괄호 내 텍스트, 미지정 시 "(미지정)")
- `title`: 항목명(최대 200자)
- `note`: 괄호 내 부가 설명(최대 200자)
- `deadline`: 마감일(`마감:` 또는 `마감일:` 뒤 날짜 YYYY-MM-DD 추출)
- `detail`: 들여쓰기된 하위 줄 내용(최대 600자)
- `priority`: 1 또는 2 (섹션 위치 기반 추론)

<!-- slide title="표시·데이터 출처·상호작용" screenshot="" -->
**표시 형태**
- rows 형태(`.rows`): 항목별 행 테이블 또는 카드 목록
- 미완료 항목을 완료 항목보다 위에 표시
- 마감일이 있으면 날짜 표시, 지난 마감일은 경고색(--action) 강조
- 담당자 레이블로 구분

**데이터 출처**: `agent/external-dependencies.md`. 이 파일은 Hermes Agent가 cron에서 자동 업데이트(차단 항목 식별)하거나 사람이 직접 편집한다. KST 23:30 cron 이후 대시보드 데이터 갱신.

**상호작용**
- 항목 클릭 → 상세 시트 (시트에서 소스 파일 링크, 북마크, 메모 가능).
- 체크 상태 변경은 대시보드 UI에서 불가. 소스 파일 직접 수정 필요.

**참고**: 사이드바에서 이 메뉴는 기본 `display:none`으로 숨겨져 있지만 라우트(`blockers`)로 직접 접근 가능하다. 항목이 있으면 카운트 배지와 함께 자동 표시될 수 있다.

## 사용가이드
<!-- slide title="외부 의존 차단 — 개요" -->

외부 의존 차단은 AI가 자동으로 처리할 수 없어서 사람이 직접 해결해야 하는 항목들을 모아 보여주는 화면입니다.

**이 화면이 왜 있나요?**
로봇팔 부품 구매, 3D 프린팅 의뢰, 실기팀 협조 요청처럼 AI 에이전트가 스스로 해결할 수 없는 일들이 있습니다. 이런 항목들이 해결되지 않으면 다음 Phase로 넘어가지 못합니다. 이 화면은 "지금 무엇이 막혀 있는가"를 한눈에 확인하는 도구입니다.

<!-- slide title="읽는 법·해결·확인 시점" screenshot="" -->
**읽는 법**
- 체크박스가 비어 있는(□) 항목이 아직 해결되지 않은 것입니다.
- 담당자 이름이 표시된 항목은 해당 담당자가 처리해야 합니다.
- 마감일이 있는 항목은 날짜를 확인해 기한을 놓치지 않도록 합니다.

**해결 방법**
이 화면에서 직접 체크하거나 수정할 수 없습니다. 실제로 해당 작업을 완료한 후 `agent/external-dependencies.md` 파일을 열어 `[ ]`를 `[v]`로 수정하면 다음 빌드 이후 완료로 표시됩니다.

**언제 확인하나요?**
아침 보고 메일을 받은 후, 또는 특정 Phase 진행이 멈춘 것 같을 때 이 화면을 확인하세요. AI 에이전트는 차단 항목을 자동으로 식별해 이 목록에 추가합니다.
