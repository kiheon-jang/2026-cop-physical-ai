## 기능명세

샘플 코드 상태 화면(`view-samples`)은 `samples/SAMPLE_STATUS.md`에 정의된 샘플 코드 파일들의 카테고리별 완성도, 마지막 검증일, 별점을 한 화면에서 확인하는 화면이다.

**헤더**
제목: "샘플 코드 상태". 부제: "samples/SAMPLE_STATUS.md · 카테고리별 완성도 / 마지막 검증일 / 별점".

**항목 목록 (samples-rows)**
`build_samples()`가 `samples/SAMPLE_STATUS.md`를 파싱해 반환한 `files` 배열에서 행 목록을 생성.

파싱 대상: `## 카테고리/ — 설명` 헤딩 → 파이프 테이블 행(파일 | 상태 | 완성도 | 마지막검증 | 설명).

각 항목 필드:
- `path`: `카테고리/파일명` 형식 경로
- `category`: 디렉토리 카테고리(예: `training/`, `inference/`)
- `status` / `status_label`: 이모지 기반 상태 (✅ complete/별4 · 🟢 basic/별2 · 🟡 wip/별1 · 📋 planned/별0)
- `completion`: 완성도 텍스트(예: "100%", "70%")
- `stars`: 정수 0~4 (차트 정렬·표시용)
- `last_verified`: 마지막 검증일
- `description`: 설명(최대 200자)

**카테고리별 요약 (summary)**
`samples.summary` 딕셔너리: `{카테고리: [complete수, basic수, wip수, planned수]}`. 행 목록 위에 카테고리별 집계 바 또는 요약 텍스트로 표시될 수 있다.

**데이터 출처**: `samples/SAMPLE_STATUS.md`. 상태 이모지(✅/🟢/🟡/📋)와 테이블 구조로 파싱. 파일이 없으면 빈 화면.

**상호작용**
- 행 클릭 → 상세 시트(소스 파일 링크, 북마크, 메모).
- 검색: 상단 검색창에서 파일명, 설명, 카테고리 검색 가능.

**참고**: 사이드바에서 이 메뉴는 핵심 메뉴(`⭐` 표시, CoP 특수 메뉴)로 분류된다.

## 사용가이드

샘플 코드 상태는 이 프로젝트에서 사용하는 파이썬 스크립트 파일들이 얼마나 완성되어 있는지 카테고리별로 확인하는 화면입니다.

**상태 아이콘 의미**
- ✅ (complete): 완전히 동작하고 검증된 코드
- 🟢 (basic): 기본 동작은 하지만 아직 개선이 필요
- 🟡 (wip): 작업 중, 완전하지 않음
- 📋 (planned): 아직 작성하지 않은 계획 단계

**마지막 검증일**
각 파일이 언제 마지막으로 정상 동작을 확인했는지 표시됩니다. 오래된 파일은 환경 변화로 동작 안 할 수 있으니 확인이 필요합니다.

**카테고리별 확인**
training/(학습 코드), inference/(추론 코드) 등 카테고리별로 묶여 있습니다. 특정 단계의 코드가 준비됐는지 빠르게 확인할 때 유용합니다.

**소스 파일 보기**
항목을 클릭하면 상세 시트가 열리고, "소스 파일 →" 버튼으로 실제 파일 경로를 확인할 수 있습니다.
