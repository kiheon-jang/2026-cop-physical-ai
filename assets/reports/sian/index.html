왜 피지컬 AI인가 — 시안 4종

내용(10개 섹션)은 네 가지 모두 동일합니다. 구성 형식만 다릅니다. 카드를 눌러 각각 스크롤해 보세요.

시안 A

논증 구조

각 섹션이 질문 → 근거 → 반론 검토로 전개. 논리를 따라가며 납득하게 하는 구성.

열기 → 시안 B

계층 구조

감지 · 조작 · 이동/인지 계층이 페이지를 관통. 상단 계층 바가 현재 위치 표시.

열기 → 시안 C

지표 브리핑

장면마다 핵심 지표 하나와 결론, 출처 구분. 가리키며 설명하기에 적합.

열기 → 시안 D

조건과 접근

현장 조건과 기술적 접근을 좌우 대응. 중간에 긍정·반대 근거 병기로 전환.
