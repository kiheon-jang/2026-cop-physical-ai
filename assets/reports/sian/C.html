화면 안→화면 밖

달라진 핵심은 하드웨어가 아니라 제어 방식입니다. 사람이 한 줄씩 작성한 프로그램 대신, 시연으로 학습한 정책이 동작합니다.

감지 기술이 빠르게 발전한 뒤에도, 왜 현장 조치는 여전히 사람의 방문으로 남아 있는가?

0% vs 0%

두 수치는 같은 문서 안에 함께 명시되어 있습니다. 감지율과 원격 조치율의 격차가 한 출처 안에서 드러납니다.

감지 계층과 조치 계층은 서로 다른 성숙 곡선 위에 있고, 지금 비어 있는 쪽은 조치 계층입니다.

산업용 로봇이 자리 잡은 영역은 대상과 환경이 고정된 공정입니다. 같은 자세로 놓인 같은 부품을 같은 순서로 다루기 때문에, 한 번 맞춰 놓은 설정이 다음 작업에도 그대로 통합니다. 승강기 유지관리는 조건이 반대입니다. 기종과 연식, 설치 환경, 기계실 배치와 접근 경로가 현장마다 다르고, 같은 건물 안에서도 호기별로 달라집니다. 이 조건에서는 장비 자체의 가격보다 현장마다 다시 맞추는 통합 비용이 훨씬 크기 때문에, 기존 자동화 방식으로는 경제성이 성립하지 않았습니다.

그래서 지난 10여 년의 기술 투자는 상태를 읽는 계층, 즉 원격 모니터링과 예지보전에 집중됐습니다. 상태를 읽는 일은 센서와 통신망으로 확장할 수 있지만, 설비에 물리적으로 손을 대는 일은 현장마다 새로 풀어야 하는 문제로 남았습니다.

실제로 산업 현장에 배치된 로봇도 계기 판독, 열화상 촬영, 가스 측정 같은 점검 작업을 맡고 있으며, 밸브를 돌리거나 패널을 여는 조작은 아직 선택 사양 수준입니다.

  • 최신 연구들은 실제로 일하게 될 환경에서 촬영된 데이터일수록 학습 가치가 크다는 점을 반복 확인하고 있습니다. 현장에서 직접 모은 데이터가 외부 데이터로 대체하기 어려운 자산이 됩니다.

어떻게 동작하나

  • 안경형 기기가 1인칭 시야와 함께 머리·손의 3차원 움직임을 기록합니다.
  • 축적된 기록은 먼저 작업 절차 표준화와 교육 자료로 쓰이며, 동시에 로봇 정책의 사전학습 자료가 됩니다.
  • 로봇 적용 단계에서는 사람 작업 데이터에 소량의 로봇 데이터를 더해 함께 학습합니다. 사람 영상이 로봇 데이터를 완전히 대체하는 것은 아니며, 필요한 로봇 데이터의 양을 크게 줄이는 역할입니다.
  • 따라서 로봇 도입 시점과 무관하게 기록을 먼저 시작하는 것이 순서상 유리합니다.

  • 교육 — 신규 인력이 문서 대신 실제 작업 시점의 영상으로 학습해 숙련 시간을 단축합니다.

  • 노하우 전수 — 오래 축적된 작업 판단이 개인 경험으로만 남지 않고 조직의 기록으로 남습니다.

수집 방식의 위치

채움색은 주력 방향, 외곽선은 병행 가능한 선택지입니다.

병행 가능한 다른 방식 · 열린 결말

1 · 착용형 외골격

로봇 팔과 같은 관절 구조의 착용 장비로 관절 각도를 그대로 기록. 로봇을 현장에 들이지 않고 로봇 좌표계에 가까운 데이터를 확보합니다. 팔당 약 40만원 수준 장비로 원격조종 데이터에 대등한 성능.

적합 — 동작 정밀도가 중요한 특정 작업 집중 기록 / 착용 부담으로 상시 사용에는 부적합 · AirExo

2 · 휴대형 그리퍼 장치

카메라와 위치 추적을 붙인 집게형 도구를 들고 작업합니다. 수집 속도가 빠르고 여러 로봇 기종으로 이식됩니다. 54개 과제 10만 건 데이터셋.

적합 — 집기·옮기기처럼 도구 형태가 단순한 작업 / 힘·촉각 정보는 남지 않음 · UMI / FastUMI

3 · 로봇 직접 조작

사람이 로봇을 직접 조종해 데이터를 남기는 정통 방식. 조작자가 로봇의 힘을 직접 느끼며 기록해 품질이 가장 높으나 장비 비용과 숙련 시간이 필요합니다.

적합 — 최종 배치 직전 소량의 고품질 데이터로 마무리 · 텔레오퍼레이션

4 · 시뮬레이션 합성

소수의 실제 시연을 물체 위치·환경을 바꿔 자동 증식. 200건 미만 시연에서 5만 건 이상 생성, 11시간에 78만 건 생성 후 실데이터 결합 시 40% 향상.

적합 — 이미 확보한 실제 데이터 증폭 / 접촉이 많거나 형태가 변하는 대상은 격차 남음 · MimicGen · GR00T N1

5 · 공개 데이터 · 파운데이션 모델

공개 대규모 데이터와 사전학습 모델 위에 자체 데이터를 얹습니다. 21개 기관·22종 로봇·100만 건 이상 궤적으로 로봇 간 전이 입증, 새 작업 하나에 1~20시간 분량으로 미세조정 가능.

적합 — 자체 데이터가 적은 초기 출발점 / 우리 환경에 맞추는 데이터는 별도 필요 · Open X-Embodiment

6 · 운영 중 데이터 축적

일정 수준의 시스템을 현장 투입 후 운영하며 쌓이는 기록과 개입 이력으로 성능을 갱신합니다. 16대 규모 실증에서 평균 성공률 95% 도달.

평가·감시 목적 사용 금지

수집된 기록은 근무 평가, 근태 관리, 징계 자료로 사용하지 않습니다. 사용 목적·범위·보관 기간을 사전에 명문화합니다.

열람·삭제 보장

본인이 자신의 기록을 언제든 확인할 수 있고, 삭제를 요청하면 지체 없이 처리합니다.

  • 현재 대상 범위는 제어반 앞 15×15cm 영역의 조작 구간. 현장 이동, 커버 개폐, 전원 차단 등 안전 절차, 대상 판단, 기종별 차이는 현재 범위에 포함되지 않음
  • 현장 작업 분석에 기반한 대상 작업 정의를 정교화하는 작업이 필요
