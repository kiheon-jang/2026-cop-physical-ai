01:02 / 23:30 회차 산출물 정독 → wrapper auto-resume glob 미스매치 발견. 1회차 작성된
`scripts/start_act_train.sh` 의 `ls -t epoch_*.pt` 패턴이 `train_act.py::_save_checkpoint`
의 실제 저장 포맷 (HF `save_pretrained` 디렉터리 = `epoch_{epoch:04d}/`) 과 불일치 →
auto-resume 영구 무효.

본 회차 Edit 패치:
1. glob `ls -t epoch_*.pt` → `ls -dt epoch_*/` 디렉터리 mtime 최신순, 후행 `/` strip + `-d`
   존재 검증.
2. 사용자가 `--resume-from` 또는 `--no-resume` 명시 시 자동 탐색 분기 생략
   (`SKIP_AUTO_RESUME=1`). 이중 인자 충돌 방지.
3. wrapper 전용 `--no-resume` 플래그 추가 → cold-start 강제용. `FILTERED_ARGS` 로 분리해
   `train_act.py` 에 전달하지 않음 (argparse 미정의 인자 거부 회피).
4. `set -u` 환경 빈 배열 unbound 회피 — `${FILTERED_ARGS[@]+"${FILTERED_ARGS[@]}"}`.
5. 헤더 주석 갱신 — `epoch_*.pt` → `epoch_*/ 디렉터리`.
