## 5. Playground IK 상세 (arm3d.js `mountArm3D` interactive 블록)

### 데이터 소스 (⚠️ 실측 확인됨)
- `pickHeroTraj(web3d)` = `web3d.policy_history[length-1]` = **최신 = 2026-08-07 `act_s1_sim` on `pcb_reset_scene.xml`** (S1 리셋버튼, **led_frame 46**, 120프레임, 성공률 1.0, median press 2.86mm). 첫 성공 rollout 사용.
- `FR` = 프레임(qpos[0:6]+cube[6:13]), `LEDF` = rollout.led_frame(46), `N`=120.
- **PRESS 포즈 = FR[LEDF] = `[0.03,0.28,-0.08,1.38,0.06,0]`** (실측 버튼 누름). restFrame FR[0]=`[-0.02,-1.62,1.43,0.88,0,0.01]`.
- 관련: `research/simulation/inference_progress/rollout_summary_s1_*.json`, ckpt `checkpoints/act_s1_sim`.

### 동작 로직 (현재)
- **자유추종(버튼 밖)**: CCD IK. ikH = j0(shoulder_pan)·j1·j2·j3. eff=inner[7](moving_jaw). 커서→카메라정면 평면(planeC 0.15,0.10,0) 투영 타깃, FLOOR_Y 0.05 하한. 보드관통 클램프 gripMinY≥BOARD_TOP(0.026, 수렴루프 3패스).
- **가동범위(실기 실측 반영)**: YAW(j0)=±0.5(실기 팬 거의 잠금 반영), j1~j4 = FR min/max ±0.15.
- **버튼 조준(BTN_SNAP=0.09 NDC, 버튼 화면좌표 기준)**: `aiming=true` → solve에서 **전 관절 ang을 PRESS로 이징(×0.28/frame)**. **성공 = |ang[1..3]−PRESS[1..3]|<0.14** 수렴 시(상승엣지 LED초록+카운트). 클릭 성공 없음.
- 버튼 월드좌표 ≈ (0.266, 0.028, 0.009). eff(피벗)는 누름 시 버튼 x·z 일치, y는 ~9cm 위(집게 손끝이 아래로 뻗음).

### 시행착오 기록 (다시 하지 말 것)
- 3D 거리 판정 → 커서→카메라평면 타깃이 버튼 깊이와 안 맞아 부정확(z 3.7cm gap).
- 스냅+aiming 판정 → 조준존 넓어 안 닿아도 성공.
- 손끝 tip 노드(집게 로컬 -x 끝) → 로컬 -x가 손끝 아님, 10cm 벗어남.
- **최종 해결 = 조준 시 실측 PRESS 프레임으로 이징 + 포즈수렴 판정.**
