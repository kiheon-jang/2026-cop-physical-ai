# 시뮬 데이터 합성 — 2026-06-03 (수)

## 작업 목표
CoP Physical AI 시뮬레이션 환경에서 200 에피소드의 데이터를 생성하고 LeRobot Dataset 포맷으로 유효성을 검증.

## 작업 수행 (Claude Code 위임)
`claude -p`를 통해 `sim_data_collector.py` 스크립트 실행을 위임하여 200 에피소드의 데이터를 수집하고 LeRobot Dataset 포맷 유효성을 검증했습니다.

## 데이터 수집 및 검증 결과 요약

### 수집 완료
| 항목 | 값 |
|---|---|
| 총 에피소드 | **200개** (0~199, 결측 없음) |
| 총 프레임 | **12,400개** (에피소드당 62프레임 균일) |
| FPS | 30 |
| 렌더링 방식 | headless (MUJOCO_GL=cgl, macOS CGL) |
| 총 디스크 사용량 | **27.3 MB** |

### LeRobot Dataset 포맷 유효성
- `LeRobotDataset` 로드 성공 (`lerobot 0.5.1`, codebase_version v3.0)
- 저장 경로: `data/episodes/` (repo_id: `local/cop-pickplace`)

| 피처 | shape | dtype | NaN |
|---|---|---|---|
| `observation.images.top` | `(3, 480, 640)` | float32 | - |
| `observation.state` | `(6,)` | float32 | 0 |
| `action` | `(6,)` | float32 | 0 |
| `timestamp` | 스칼라 | float32 | - |
| `episode_index` | 스칼라 | int64 | - |

### 구조
```
data/episodes/
├── data/chunk-000/file-000.parquet  (12,400행 테이블)
├── videos/observation.images.top/chunk-000/file-000.mp4  (25.7 MB, h264)
└── meta/
    ├── info.json  (total_episodes: 200, total_frames: 12400)
    ├── stats.json (action/state 평균·분산 포함)
    └── tasks.parquet  (task: \"pick and place red cube\")
```

- action 범위: `[-1.30, 2.10]` rad, state 범위: `[-1.30, 1.58]` rad — 물리적으로 유효한 값
- timestamp: 0초부터 0.0333초 간격으로 단조 증가 (30fps 정합)

데이터셋은 LeRobot 포맷을 충족하며 ACT/Diffusion Policy 학습에 바로 사용할 수 있는 상태입니다.
