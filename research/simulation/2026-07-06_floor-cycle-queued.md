# 바닥(받침대 없음) 사이클 예약 + 씬-데이터셋 정합 배선 (2026-07-06 오후)

## 결정
마크 요청: "박스(받침대) 없는 씬으로 처음부터 다시 학습 — 리소스가 적으면 진행".
리소스 실측: 수집 ~15분(CPU, 병행) + 학습 ~10h(MPS, 야간 유휴) + 측정 ~5분, 비용 0원, 디스크 ~10GB(여유 894GB)
→ **진행**. 단 진행 중인 DR 사이클(W1 비교, 7/7 00:20 완료 예정)을 보호하기 위해 **예약 큐** 방식.

## 실행 내역
1. **바닥 데이터 수집 시작** (14:2x, DR 학습과 병행): `data/episodes_floor` 50ep,
   scene_grasp_floor.xml (큐브 z=0.015). expert 바닥 성공률 100% 사전 검증됨(같은 날 문서 참조).
2. **씬-데이터셋 정합 배선**: 드라이버가 DS_BASE 로 씬을 결정해 `COP_SCENE` export —
   `*floor*` → scene_grasp_floor.xml, 그 외 → scene_grasp_pads.xml. 수집기 `--scene`(바닥이면
   TABLE_TOP=0 배치), 측정기 COP_SCENE(+큐브 초기 z 자동), traj payload 에 `scene` 기록.
   → 3D 뷰어가 바닥 씬 에피소드에서 받침대 메시를 자동 숨김.
3. **다음 사이클 예약**: `logs/cop_dataset_target.next` = `data/episodes_floor`.
   드라이버 stage 6(완료/유지) 도달 시에만 `.next` 를 승격하고 `exec` 재평가 1회
   → **현 사이클(DR)의 측정까지 끝난 뒤에야** 바닥 학습이 시작된다.
