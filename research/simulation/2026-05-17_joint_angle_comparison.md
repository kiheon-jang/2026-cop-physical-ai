# 🛠 시뮬 환경: 관절 각도 비교 스크립트 준비 — 2026-05-17

## 1. 개요
Phase 0 W3 (5/15 ~ 5/21)의 첫 번째 작업인 "동일 명령에 대한 시뮬 vs 실기 관절각 비교 (목표 ±1°)"를 위해 시뮬레이션 환경에서 관절 각도를 기록하는 Python 스크립트를 준비했습니다. 이 스크립트는 향후 실기 로봇과의 비교 검증을 위한 기반이 될 것입니다.

## 2. 수행 작업
- `samples/training/sim_joint_angle_comparison_script.py` 파일 생성
  - **목적**: MuJoCo 시뮬레이션에서 SO-ARM101 로봇의 각 관절에 sin 파형 명령을 가하고, 관절 각도를 기록합니다.
  - **상세**:
    - `SO-ARM100/Simulation/SO101/so101_new_calib.xml` MJCF 모델 로드.
    - `shoulder_pan`, `shoulder_lift`, `elbow_flex`, `wrist_flex`, `wrist_roll`, `gripper` 6개 관절 제어.
    - 각 관절에 대해 진폭 0.5 rad, 주파수 1Hz의 sin 파형 명령을 5초간 인가.
    - 각 관절마다 위상 오프셋을 주어 독립적인 움직임 시연.
    - 100Hz (0.01초 간격)으로 각 관절의 각도를 측정하여 출력.
    - 출력 형식: `시간 관절1_각도 관절2_각도 ...`

## 3. 검증 (스크립트 실행)
작성된 스크립트를 `.venv` 환경에서 실행하여 정상 동작 및 출력 형식을 확인했습니다.

```bash
/Users/markmini/Documents/dev/2026-cop-physical-ai/.venv/bin/python3 samples/training/sim_joint_angle_comparison_script.py
```

**스크립트 출력 예시 (일부):**
```
0.000 0.000000 0.000000 0.000000 0.000000 0.000000 0.000000
0.010 0.001267 0.001891 0.002244 0.002594 0.002816 0.002826
0.020 0.005451 0.006756 0.007895 0.008964 0.009669 0.009696
... (총 500줄) ...
5.000 -0.315312 -0.041306 0.220990 0.442619 0.504337 0.347077
```
(전체 출력은 스크립트 실행 로그 참조)

출력된 데이터는 시간 경과에 따른 각 관절의 위치를 나타내며, 시뮬레이션이 의도한 대로 동작하고 있음을 확인했습니다.
