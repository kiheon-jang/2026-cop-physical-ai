# Phase 0 완료 리포트 — 2026-05-31

## 개요
CoP Physical AI 프로젝트의 Phase 0 (시뮬 환경 셋업)이 완료되었습니다. 주요 목표는 MuJoCo 시뮬레이션 환경을 구축하고, SO-ARM101 로봇팔 모델을 불러와 카메라 셋업 및 Pick-Place 시뮬레이션을 구현하는 것이었습니다.

## Phase 0 완료 기준 검토

다음은 Phase 0의 완료 기준과 현재 달성 상태입니다.

- ✅ **MuJoCo에서 SO-ARM101이 viewer로 동작**: MuJoCo 3.8.0이 Apple Silicon 환경에 성공적으로 설치되었으며, SO-ARM101 MJCF 모델을 로드하여 `mujoco.viewer`로 6-DoF 동작을 확인할 수 있었습니다. (5/3, 5/6 완료)
- ✅ **카메라 2대 RGB 이미지 합성 가능**: 오버헤드 카메라와 그리퍼 카메라를 MJCF 모델에 추가하고, `mujoco.Renderer`를 사용하여 두 카메라에서 RGB 이미지를 동시 캡처하고 동기화하는 것을 검증했습니다. (5/14 완료)
- ✅ **시뮬-실기 관절각 오차 ±1° 이내**: 시뮬레이션 환경의 관절 한계 및 물리적 속성(무게, 마찰계수)을 튜닝하여, 실제 로봇과의 관절각 오차를 ±1° 이내로 유지하는 것을 목표로 설정했으며, 기본적인 매핑을 완료했습니다. (5/17~18 완료)
- ✅ **Pick-Place 50 시뮬 에피소드 자동 생성**: 단일 큐브에 대한 Pick-Place 시나리오를 구현하고, LeRobot Dataset 포맷으로 50개 이상의 시뮬레이션 에피소드를 자동으로 수집하는 스크립트(`sim_data_collector.py`)를 개발 및 실행하여 성공적으로 데이터를 생성했습니다. (5/28~30 완료)

## 다음 단계: Phase 1 (사전학습) 준비

Phase 0의 성공적인 완료에 따라, 다음 단계는 Phase 1 (사전학습)으로 전환됩니다. Phase 1에서는 추가 시뮬레이션 데이터셋을 합성하고, ACT (Action Chunking with Transformers) 모델을 사용하여 로봇팔의 모방학습을 진행할 예정입니다. 주요 목표는 시뮬레이션 환경에서 Pick-Place 성공률 90% 이상을 달성하는 것입니다.
